# 독도까지 · 한국어 웹 재구성

Unity를 사용하지 않는 독립적인 JavaScript 게임입니다. 한국어 메뉴, 한글 음절 11,172자를 포함한 Noto Sans KR 글꼴, Three.js 렌더러를 로컬에 포함합니다. 외부 API, 계정, CDN이 필요하지 않습니다.

## 실행

[게임 다운로드 (ZIP)](https://github.com/kosang02/-/raw/refs/heads/main/downloads/dokdo-korean.zip) · [전체 소스 다운로드 (ZIP)](https://github.com/kosang02/-/raw/refs/heads/main/downloads/dokdo-korean-source.zip)

게임 ZIP을 풀고 `dokdo-korean.html`을 브라우저로 열면 됩니다.


- 단일 파일: `dokdo-korean.html`을 최신 Chrome, Edge, Firefox, Safari로 열기. 파일을 내려받아 브라우저로 여세요. WebGL이 필요합니다.
- 소스: 이 폴더에서 `python3 -m http.server 8080 --directory dist`를 실행하고 `http://localhost:8080` 열기.
- 검사: Node.js 20 이상에서 `npm test`.
- 단일 파일 재생성: `python3 scripts/package.py`. 기본 출력은 `artifacts/`입니다. `--output <경로>`로 출력 폴더를 지정할 수 있습니다.

## 그래픽 업데이트 (v2.1)

원본 복원판의 스크린샷을 비교해 카메라 방향, 각진 절벽/암봉, 나무 선착장, 선박/돛 문양, 물결과 반사, 세로형 강화 메뉴를 다시 만들었습니다. 자세한 관찰 내용과 현재 화면은 [그래픽 비교 기록](docs/VISUAL-STUDY.md)에 있습니다.

## 조작

바다를 누르고 끌어서 조종합니다. 방향키/WASD로도 이동합니다. 바다를 두 번 누르면 해당 위치로 자동 항해합니다. 해도에서 섬을 선택해 항로를 설정할 수 있습니다. 적을 배의 좌우에 두면 대포가 자동 발사됩니다.

수비선을 모두 물리친 후 선착장에 접근하면 점령합니다. 소유한 항구에서 정박하면 수리·강화·시장·조수 메뉴를 이용할 수 있습니다. 내 섬의 선착장 근처에서 항해 중이면 자동으로 낚시합니다. 아레나 입구 근처에서 아레나 버튼이 나타납니다. 다른 바다 이동은 정박 중에 가능합니다.

기록은 브라우저에 10초마다, 주요 행동마다 저장됩니다. 설정에서 JSON 파일을 내려받거나 불러올 수 있습니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 주소나 파일 위치에서 실행하면 기록을 공유하지 못할 수 있으므로 백업을 권합니다.

## 원본에서 확인해 반영한 내용

분석 기준은 DOKDO Android 1.4.2 APK입니다. 원본 코드를 배포물에 포함하지 않았습니다.

- 독도/피사 두 해역, 28+19개 섬과 실제 항구 좌표, 별도의 독도 지형과 아레나/거대 문어 위치
- 동전·물고기·목재·철·은·금·다이아몬드 7종 자원
- 초기 500동전, 선체10단계, 기타 장비의 선체×5 강화 한도(최대50)
- 단계별 강화 비용, 체력/공격력, 선체별 대포 수, 시장 가격/재고/초기화 시간
- 조수3명, 갈매기2마리, 네시, 보급품 수거와 구매/강화 비용
- 어획량/고갈 계산, 수비선 수, 점령 보상, 적 전리품, 아레나 보상

## 재구성 범위와 차이

**원본과 완전히 동일한 포팅은 아닙니다.** 화면·모델·물리·인공지능·효과음은 새로 만들었습니다. 섬은 절차적으로 생성한 지형이며 피사의 연속된 운하/건축물도 원본 그대로는 아닙니다. 항구 이름의 한국어 음역은 새 번역입니다. 원본 음악, 텍스처, 애니메이션, 튜토리얼 연출은 포함하지 않았습니다.

배의 추진/선회 공식의 원래 힘 수치는 유지하지만 JavaScript 이동 모델에 맞춰 환산합니다. 원본 물리 엔진과 완벽히 동일한 조종/충돌/전투는 아닙니다. 조수 배는 별도의 체력/부활 흐름 없이 플레이어를 따라 공격합니다. 원본의 갈매기/네시 개별 행동도 단순화했습니다. 오프라인 어획은 최대4시간까지 지원합니다. 항구 무료 복귀는 전체 회복을 적용합니다. 광고, 결제, 서버 순위, 일일 보상은 구현하지 않았습니다. 원본 시장 UI의 판매가 표기80%와 실제90% 불일치는 실제 거래값90%로 표시합니다.

전투에서 120 거리 밖으로 벗어나거나 정박하면 미점령 섬의 수비선 진행이 초기화됩니다. 숫자와 기능 검증은 `tests/game.test.mjs`를 참고하세요.

## 라이선스

독립 작성한 엔진/렌더링/UI 코드와 절차적 그래픽은 이 재구성 프로젝트의 코드입니다. 원작 게임 명칭 및 원작 권리는 각 권리자에게 있습니다. 공식 서비스가 아닙니다.
- Three.js r160: MIT, `THREE-LICENSE.txt`
- Noto Sans KR: SIL Open Font License 1.1, `dist/fonts/OFL.txt`
- 폰트는 weight450으로 고정하고 필요한 Unicode 범위를 추린 WOFF2입니다. 한글 음절 전체와 자모를 포함합니다.

브라우저 검증 스크립트 `tests/browser.cjs`는 이 개발 환경의 Playwright/Chromium 경로를 사용합니다. 다른 환경에서는 설치 경로를 바꿔야 합니다.
